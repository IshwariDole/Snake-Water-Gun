# 🐍 Snake Water Gun Game

A simple **Snake Water Gun** game built using **Python**. The user plays against the computer, which randomly selects Snake, Water, or Gun.

## 🎮 Game Rules

The game follows these rules:

| Choice   | Beats    |
| -------- | -------- |
| 🐍 Snake | 💧 Water |
| 💧 Water | 🔫 Gun   |
| 🔫 Gun   | 🐍 Snake |

If both the player and computer choose the same option, the game is a **Draw**.

```

### 3. Run the Python program

```

## 🎯 How to Play

When the program starts, enter:

```text
s → Snake
w → Water
g → Gun
```

Example:

```text
Enter your choice: s
Computer chose: Water
You chose: Snake
You Win
```
